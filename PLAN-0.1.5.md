Shared implementation contract:
- HistoryQuery: int PeriodMinutes=60, int BucketMinutes=5; Validate() enforces 1..1440 minutes, bucket<=period, ceil(period/bucket)+1<=300; equality is by these two values.
- HistoryBar: DateTimeOffset From, To, LastAt; int Count, SuccessCount; double DnsTotalMs, HttpsTotalMs; bool LastSuccess. Mean timings are totals/count; FailedCount=Count-SuccessCount.
- ChannelHistorySeries: string ProfileId, ContextKey; List<HistoryBar> Bars; computed TotalChecks, TotalSuccesses, SuccessPercent, MeanMs.
- HistoryReport: HistoryQuery Query; DateTimeOffset From, To; string MonitoringKey; List<ChannelHistorySeries> Channels; string? Warning.
- ChartHistoryArchive: int Version=1; implementation-owned stored minute series. Record(AppConfig config, IEnumerable<ProbeResult> results, DateTimeOffset now); Seed(AppConfig config, IEnumerable<ProfileStats> statistics, DateTimeOffset now); Query(AppConfig config, HistoryQuery query, DateTimeOffset now) -> HistoryReport. static ContextKey(ChannelProfile profile, string monitoringKey); static SortProfiles(IEnumerable<ChannelProfile>,HistoryReport) -> ChannelProfile[].
- RpcRequest adds HistoryQuery? History; RpcReply adds HistoryReport? History (omit when null). Command history is read-only and returns only History, without Status.
- UiBackend.ReadHistoryAsync(HistoryQuery query,CancellationToken token) -> Task<HistoryReport>; reject an unknown service source or outdated service explicitly; local engine read is allowed only when local observation/diagnostics is the actual source.
- ChannelHistoryView.Query getter returns a detached HistoryQuery; event EventHandler? QueryChanged; UpdateHistory(AppStatus) keeps status/context; SetReport(HistoryReport), SetHistoryError(string), SetLoading() update chart display. It may synthesize bounded current-history reports from status only for explicit smoke, never claim these are a full day. Caller ignores stale query responses.
- MainForm owns async fetching, query/source key, cancellation, 20-second refresh while Journal tab is visible and action priority. No automatic probe requests for chart refresh.

Independent agents own model/tests, view-only UI, and engine/RPC/backend respectively. Root owns MainForm wiring/version/release and verifies their evidence. No repeated reviewer gate is required.

Additional authorized sharing implementation:

- DnsShareOffer: List<DnsShareCandidate> Profiles; optional Warning. DnsSharing.Select(AppConfig,IEnumerable<ProfileStats>,DateTimeOffset) returns the offer, reads raw per-site results and excludes all built-in effective configurations. Official known ChatGPT contexts only; fixed Gemini evidence; reject private/reserved DNS and stale/future successes.
