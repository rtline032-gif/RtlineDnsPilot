RtlineDnsPilot 0.1.17 — рабочие каналы сверху и переподключение приложений.

Рабочие каналы со свежими успешными проверками теперь расположены сверху. Внутри этой группы сначала более стабильные, затем с меньшим временем ответа. Выбранная строка, галочки и синий активный канал сохраняются. Порядок хранения каналов и опроса не меняется.

Новая отдельная кнопка «Переподключить приложения» предлагает выбрать Chrome и/или Codex. Помощник с разрешением Windows очищает системный DNS-кэш и вручную сбрасывает подходящие внешние TCP/IPv4-соединения HTTPS выбранных приложений текущего пользователя в текущем сеансе. Окна остаются открыты, текущие запросы и соединения других вкладок выбранного Chrome прерываются. Результат показывает число сброшенных, изменившихся, ошибочных и пропущенных IPv6-соединений.

IPv6, QUIC и внутренний DNS-кэш приложений не сбрасываются. Полный перезапуск приложения иногда всё равно потребуется. Доступность аккаунта, генерация и активная сессия Codex зелёным публичным HTTPS-тестом не подтверждаются. Сброс не выполняется автоматически при переключении DNS.

В поставке сохраняются 26 известных публичных DNS-профилей, пользовательские каналы, настройки и история. Системные DNS-настройки, VPN, прокси, маршруты, адаптеры и служба этой кнопкой не перенастраиваются.

В 0.1.12 и новее нажмите «Обновить программу». Старые 0.1.10/0.1.11 используют GitHub API и зависят от его лимитов; версии без кнопки требуют ручного перехода. При обновлении установленной службы Windows запросит разрешение. После её обновления управление DNS остаётся выключенным; включите его отдельной кнопкой.

Сборки: Windows 10/11 x64 с .NET Desktop Runtime 10 и отдельный вариант совместимости Windows 7 SP1 x64 с .NET Desktop Runtime 6.0.36. Нативная приёмка Windows 7 и настоящий сброс соединений остаются отдельными проверками; локально пройдены 516 проверок .NET 10 и 549 проверок .NET 6 на Windows 10. Изменения реальных DNS/службы, запуск UAC и сброс живых соединений при разработке не выполнялись. Ранний выпуск без цифровой подписи.
