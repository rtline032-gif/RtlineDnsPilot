# RtlineDnsPilot 0.1.25

- Добавлен GeoHide EU (DoH) с адресом `5.175.161.40` и шаблоном `https://eu.geohide.ru/dns-query`. Для GeoHide EU доступен и обычный DNS.
- При обновлении программа удаляет семь распознанных штатных профилей: обе версии Xbox DNS, три Comss.one, Bezmezhau (UDP/TCP) и GeoHide (UDP/TCP). Для удаления должны совпасть ID, имя и параметры прежней поставки. Собственные записи с другим ID или изменёнными параметрами сохраняются.
- Нажмите «Обновить программу». GeoHide EU (DoH) добавится автоматически. В поставке 26 профилей, в списке можно хранить до 32.
