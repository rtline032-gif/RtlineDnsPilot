The UI runs without administrator privileges. Monitoring can run alone. Enabling management installs a local automatic Windows service through an explicit UAC action in the application. The service owns loopback UDP and TCP DNS listeners, profiles, probes, selection and a write-ahead DNS restoration journal. Service recovery restarts it after a crash. At each service start it restores an incomplete old transaction before considering a new activation. Disabling restores DNS before stopping the relay; normal service stop does the same. A restoration error preserves the journal and blocks new activation.

The service uses the selected adapter GUID, resolves its current index at each mutation, snapshots IPv4 and enabled IPv6 DNS source (automatic/static) and ordered address list. It sets only DNS to 127.0.0.1 and ::1 using netsh, verifies results, and records the transaction before any mutation. Any partial failure triggers rollback. Do not restore over a third-party replacement of DNS; expose a conflict. Do not silently turn a DoH profile into plaintext. Profiles use explicit upstream/bootstrap IPv4/IPv6 addresses. DoH uses HTTPS with normal TLS certificate validation and the provider hostname as SNI, pinned bootstrap connectivity and no system-DNS bootstrap recursion. UDP falls back to DNS-over-TCP on a truncated response. The relay accepts only local queries, validates transactions and question matching, preserves TTLs, uses bounded concurrency and deadlines, and does not log browsing DNS questions. The operating system supplies DNS caching.
