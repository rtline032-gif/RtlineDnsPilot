# RtlineDnsPilot 0.1.31

- В режиме автовыбора Pilot проверяет системный DNS Windows даже когда сайт отвечает на прямую проверку канала.
- При сбое Pilot очищает DNS-кэш и повторяет проверку. Если ошибка сохраняется, он пробует один подтверждённый резервный канал.
- Если резерв тоже не работает или его нет, Pilot восстанавливает исходные настройки DNS адаптера и переходит в наблюдение. Результат записывается в журнал.
