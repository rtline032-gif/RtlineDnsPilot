RtlineDnsPilot 0.1.18 — подробная диагностика соединений.

Добавлена «Диагностика канала»: последнее сохранённое измерение с отдельными результатами DNS A/AAAA, адресами и выполненными попытками к каждому целевому IP. Для каждой попытки показаны TCP, TLS, HTTP-заголовки, времена, код ответа и фактическая версия HTTP. Не начавшийся TLS не называется плохим сертификатом, сброс после успешного TLS не превращается в ошибку TCP. Последующие попытки не стирают предыдущие.

Окно только читает и позволяет вручную скопировать данные. Новая проверка и сетевые изменения не запускаются. Полные фазы хранятся для последнего измерения и передаются отдельным ограниченным ответом по одному каналу. Числовая история и статистика сохраняются; в старых измерениях отсутствие деталей отмечено явно. Для данных службы нужна служба версии 0.1.18.

Каталог проверен 17.11.2026: временно недоступный Xbox выключен в новом наборе; старые статические Zapret сохранены с предупреждением о текущем DoH через Cloudflare без постоянного IP. Динамический bootstrap не реализуется подстановкой случайного IP. Все 26 конфигураций и ID сохранены. Пользовательские enabled, заметки, выбор, история и удаления не меняются; ревизия каталога не повышается ради обновления метаданных.

Штатные сертификаты/SNI, предпочтение HTTP/2 на современной Windows, fallback, тайм-ауты и порядок IP сохранены. Успешные проверенные CDN IP ChatGPT не закрепляются. Внешние TCP/TLS-отказы без VPN этим патчем не объявляются исправленными. Публичный trace не подтверждает авторизацию, генерацию или streaming.

Для обновления нажмите «Обновить программу». Если установлена фоновая служба, Windows запросит разрешение на её обновление. После обновления службы управление DNS остаётся выключенным; включите его отдельной кнопкой. Подробная диагностика службы доступна после обновления до 0.1.18 и нового штатного измерения.

Сохраняются отдельные сборки Windows 10/11 x64 (.NET Desktop Runtime 10) и совместимости Windows 7 SP1 x64 (.NET Desktop Runtime 6.0.36). Локально на Windows 10 пройдены 539 проверок .NET 10, 572 проверки .NET 6 и 40 проверок приёмника с имитацией Google. Нативная Windows 7 и сеть проблемного Windows 11 не проверялись. Ранний выпуск без цифровой подписи.
