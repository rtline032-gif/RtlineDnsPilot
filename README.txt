RtlineDnsPilot 0.1.29

Локальный монитор DNS-каналов для Windows. Проверяет выбранные публичные
HTTPS-адреса через каждый DNS, ведёт статистику и выбирает доступный канал
с приоритетом стабильности или времени отклика. DoH URL необязателен:
пустой URL означает обычный DNS UDP/TCP; при заданном URL используется DoH
с проверкой сертификата, без автоматического перехода на открытый DNS.

В таблице показаны время и результат последней проверки. Старые замеры
отображаются серым с подписью «Был доступен» или «Был недоступен».

ЧАСТОТА ПРОВЕРОК КАНАЛОВ
Пока есть рабочий канал, резервы с тремя сбоями подряд за две минуты
или дольше проверяются реже. Между их проверками проходит минимум
десять минут и минимум пять обычных интервалов. После успешной проверки
возвращается обычная частота. Если рабочие каналы пропали, резервы
проверяются в том же раунде. «Проверить сейчас» проверяет все включённые.

ОТКАТ ОБНОВЛЕНИЯ
Рядом с «Обновить программу» находится «Откатить обновление». Она
возвращает версию до последнего завершённого обновления из локальной
копии. Для установленной службы нужен её защищённый снимок. Windows
запросит разрешение. Исходный DNS восстановится до замены службы.
Проверки и настройки сохранятся, управление DNS можно включить отдельно.
Выбранная версия открывается при следующем запуске. Чтобы снова получить
свежий выпуск, нажмите «Обновить программу».

ИСПРАВЛЕНИЯ DNS И ДИАГНОСТИКА 0.1.21
Фатальная остановка DNS-посредника обрабатывается независимо от паузы
проверок. Сначала восстанавливаются DNS Windows, затем закрывается relay.
Если восстановление не удалось, журнал сохраняется и показывается Pending;
повтор — кнопкой «Отключить управление / восстановить DNS».
После фатального отказа автоматического повторного включения управления нет.

«Диагностика посредника» читает метаданные реальных запросов локального
relay: тип и класс записи, UDP/TCP и IPv4/IPv6 транспорта, профиль/контекст,
попытки upstream, RCODE заголовка, этап и безопасный код ошибки. Имена сайтов,
пакеты и токены не записываются; в памяти — 32 последних завершения и 32
негативных/ошибочных результата за последние 5 минут. Чтение не запускает
сетевые пробы. При остановке процесса данные теряются.
Эта диагностика не проверяет Windows getaddrinfo или получение ответа
приложением. Для неё нужна отвечающая служба 0.1.21 или новее.

Встроенная проверка подписана «HTTPS ChatGPT»: публичный HTTP 200 сам по
себе не подтверждает работу Codex. Диалог автоматического DNS явно поясняет,
что служба будет остановлена и отключена. Обычное отключение управления
возвращает исходный DNS, сохраняя работающую службу.

не подтверждает вход в аккаунт, ответ модели или streaming.

и статистика автовыбора сохраняются.

Пользовательские каналы, enabled, примечания и удаления сохраняются.

ИСПРАВЛЕНИЯ 0.1.16

монитор пробует следующий IP в пределах прежнего общего тайм-аута.
Полученный HTTP-ответ завершает проверку: отказы 403/429/5xx не скрываются

ОБНОВЛЕНИЕ И КАТАЛОГ DNS
Кнопка «Обновить программу» получает проверенный пакет из официального
GitHub Releases. В выпуск включено 30 публичных DNS-профилей.
Новая ревизия каталога добавляет все отсутствующие профили; существующие

Предел — 32 профиля. Если места не хватает, программа сохраняет свои

после обновления службы управление DNS остаётся выключенным.
Включить/выключить канал можно нажатием на галочку или пробелом в её ячейке.
Подсказка у имени и результата сначала показывает последнюю фактическую

Gemini из-за прежнего предела 16 КБ. Тайм-ауты DNS или запрет соединения

КАК ПОЛЬЗОВАТЬСЯ
«Что проверять»: выберите ChatGPT/Codex, Gemini, Tailscale либо добавьте
свои публичные HTTPS-адреса; примените изменения. Для зелёного общего
результата должны пройти все включённые проверки данного канала.
Зелёный означает свежую успешную проверку, красный — ошибку, серый —
нет свежих результатов/канал выключен. Активный канал выделен синим.
Подробная причина доступна при наведении мыши на результат.

«Каналы»: добавление, изменение, удаление, проверка дубликатов, импорт
и экспорт JSON. В архив включены 15 публичных профилей; их доступность
определяется вашими измерениями. Источники адресов перечислены в CHANNELS.txt.
Автовыбор предлагает самый стабильный или самый быстрый по времени ответа
канал. Защита от частых переключений сохраняется. Правая кнопка мыши:
ручная фиксация постоянно/на время, предпочтение, возврат к автоматике.
Ручная фиксация отключает автоматическое переключение при отказе до её снятия.

Окно запускается без прав администратора. «Включить управление DNS»
запрашивает разрешение Windows на установку/обновление локальной службы.
Служба направляет DNS выбранного физического адаптера на 127.0.0.1/::1
и пересылает запросы выбранному провайдеру. Поэтому эти адреса в свойствах
адаптера нормальны при включённом управлении. Служба продолжает работать
при закрытом окне. «Пауза проверок» останавливает измерения; это отдельное
действие от выключения управления системным DNS.

«Отключить управление»/«Восстановить DNS» возвращают сохранённый исходный
режим и порядок DNS. «DNS автоматически (DHCP)» — отдельный явный сброс
DNS выбранного адаптера на автоматическое получение. IP-адрес, VPN,
прокси, маршруты, Wi-Fi и привязки протоколов приложение не меняет.
При незавершённом восстановлении сохраняется журнал; сторонние изменения
DNS не перезаписываются автоматически. Не удаляйте dns-session.json и
его резервную копию вручную. После обновления службы управление выключено;
включите его заново только после проверки состояния.

«Журнал»: события и графики по каналам, выбор периода и размера одного
столбца. Каналы располагаются по измеренной стабильности. Красный столбец
показывает сбой в интервале. Миллисекунды — задержка DNS/HTTPS, не скорость
загрузки или генерации. Выбор периода графика не меняет частоту проверок.

«Обновить программу»: одна явная проверка публичного файла updates.json
в официальном репозитории rtline032-gif/RtlineDnsPilot, без GitHub API,
токенов и фоновых запросов обновления. Сохраняются проверка адреса,
SHA-256, состава архива и версии файлов. Обычный вариант принимает только
win-x64, Windows 7 — только win7-x64. Папки загрузки/запуска обновлений
раздельные; .NET 10 пакет не предлагается варианту Windows 7.
Если совместимый выпуск ещё не опубликован, новая версия не предлагается.
Во время обновления отдельный помощник ожидает завершения окна и при
ошибке возвращает прежний запуск. Пользовательские данные сохраняются.

«Поделиться DNS»: только по явному нажатию отправляет владельцу каталога
дополнительные публичные DNS, для которых сохранена свежая успешная
проверка ChatGPT/Gemini. Базовые профили и личные настройки исключаются.
Получателя менять не нужно. Полный перечень передаваемых данных — в PRIVACY.md.

ГРАНИЦЫ ПРОВЕРОК
Проверяется публичная HTTPS-доступность. Авторизация, генерация ответа
и рабочее WebSocket-соединение Codex/Gemini не проверяются. Tailscale —
доступность страницы входа, не состояние VPN-туннеля. Страна показывается
только если сам проверяемый сайт сообщил её для анонимного подключения;
иначе «Не определена». Это не гарантированный регион учётной записи.
DNS-провайдер может быть недоступен независимо от совместимости Windows.

ЧИСТОТА АРХИВА И ПРОВЕРКА
Архив содержит программу, публичные профили, документы и SHA256SUMS.txt.
Личные каналы/конфигурация, адаптеры, сеть, журналы и статистика разработчика
не включаются. Проверки разработки выполнялись без изменения системного DNS,
установки/остановки службы и UAC. Сборка и тесты .NET 6 на Windows 10 сами
по себе не доказывают работу на конкретном Windows 7: на нём ещё нужно
проверить HTTPS, включение службы и восстановление DNS.
