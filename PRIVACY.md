# Конфиденциальность / Privacy

Действует для опубликованных исходников RtlineDnsPilot 0.1.8. Дата: 23 октября 2026 года.

## Локальные данные

Приложение хранит DNS-профили, выбранный адаптер, объекты мониторинга, результаты, страну подключения, если её явно сообщил проверяемый сайт, и журнал событий на компьютере пользователя. Локальные данные находятся в `%LOCALAPPDATA%\NetPilot`, данные службы и восстановления DNS — в `%PROGRAMDATA%\NetPilot`. Служба устанавливается в `%ProgramFiles%\NetPilot`.

Измерения нужны для сравнения каналов и графиков. Архив графиков охватывает последние 24 часа; история выбора хранит до 120 последних измерений на канал. Журнал восстановления DNS содержит исходные настройки адаптера и нужен для безопасного возврата к ним. Не публикуйте эти каталоги целиком.

## DNS и HTTPS

При проверках выбранные DNS-провайдеры получают запросы имён проверяемых сайтов. При включённом управлении DNS выбранный провайдер также обслуживает DNS-запросы компьютера через локальный посредник. UDP/TCP DNS передаётся без шифрования; DoH использует HTTPS. Программа не подменяет сертификаты HTTPS и не читает учётные данные сайтов.

Выбранные сервисы получают обычные HTTPS-запросы без входа в аккаунт и cookies. По умолчанию проверяется `https://chatgpt.com/cdn-cgi/trace`; Gemini, Tailscale и свои объекты включаются пользователем. DNS-провайдеры, проверяемые сайты и промежуточные сети могут видеть сведения о сетевом соединении, включая внешний IP, который им доступен. При использовании посредника провайдера сайт может видеть IP этого посредника.

Страна берётся только из явного ответа самого проверяемого сайта. Ответ может содержать другие технические поля; приложение сохраняет код страны, а не полный ответ trace. Страна подключения не равна стране аккаунта.

## «Поделиться DNS»

Отправка выполняется только по нажатию кнопки. При запуске, обычном мониторинге и открытии вкладок автоматической передачи в каталог владельца нет. Если подходящих каналов нет, запрос не отправляется.

Из дополнительных каналов, отсутствующих в базовом наборе, отбираются публичные DNS с сохранённой успешной публичной проверкой ChatGPT или Gemini за последние 24 часа. Передаются протокол, публичные DNS-адреса, порт, DoH URL и отметки успешных проверок ChatGPT/Gemini.

В полезную нагрузку не включаются имя пользователя или компьютера, адаптер, исходные настройки сети, IP подключения пользователя, имена/ID/примечания локальных профилей, собственные объекты мониторинга, страны, подробная статистика и журналы. Как при любом HTTPS-запросе, Google и сетевые посредники могут видеть адрес источника на уровне соединения. Отсутствие IP в JSON не скрывает его от сетевого получателя.

Получатель — каталог владельца проекта `rtline032-gif` в Google Drive через один встроенный публичный Google Apps Script URL. Отправитель не выдаёт доступ к своему Google Drive. Записи каталога считаются пользовательскими сообщениями о доступности, могут быть прочитаны и сохранены владельцем/читателями каталога и не включаются автоматически в базу приложения. Не отправляйте DNS, которые не предназначены для публичного распространения. Каталог ограничен объёмом и квотами, но гарантированный срок удаления принятой записи не установлен.

Приложение не добавляет рекламу, стороннюю аналитику или автоматическую отправку локальных журналов. Проверки HTTPS, обычные DNS-запросы и явная отправка DNS являются описанными выше сетевыми обращениями.

## Управление данными

Выбор сервисов и DNS выполняется в приложении. Для остановки проверок используйте паузу. Для прекращения использования локального DNS-посредника восстановите исходные DNS или выберите автоматический DNS. Для полного удаления сначала восстановите DNS и удалите службу, затем удалите папку программы и локальные данные. Данные восстановления не следует удалять до завершения восстановления.

Вопросы об обработке данных можно направлять владельцу через [профиль GitHub](https://github.com/rtline032-gif) или Issues проекта. Не размещайте личные данные в публичном Issue.

## English summary

Configuration, adapter recovery state, measurements, country evidence and event history are stored locally. DNS providers receive DNS queries; selected public HTTPS endpoints receive anonymous reachability requests. Networks and remote services can observe connection metadata, including the source IP available to them. The app does not sign in to monitored services.

The optional **Share DNS** button sends only eligible additional public DNS settings and ChatGPT/Gemini public-check flags to the project owner's Google Apps Script/Drive catalogue. It does not upload local names, device identifiers, adapter settings, custom monitoring URLs, country history or logs. Source IP is not a JSON field, but Google can observe it at the transport layer. Shared settings may remain in the catalogue and be copied by its readers; no guaranteed removal period is specified. There is no background catalogue upload, advertising analytics or automatic log upload.

## Обновление программы, версия 0.1.10

Кнопка «Обновить программу» обращается к API GitHub и серверам скачивания
официального репозитория rtline032-gif/RtlineDnsPilot. GitHub получает обычные
сведения HTTPS-соединения, включая доступный ему IP и строку приложения с
версией. Каналы, объекты проверок, журналы, имя компьютера и данные аккаунтов
в запрос обновления не передаются; авторизация GitHub не используется.

Приложение скачивает публичный ZIP и проверяет его SHA-256. Прежняя программа,
кеш новых версий, контрольные суммы, указатель выбранной версии, задания
перезапуска и путь к существующей папке данных сохраняются локально в
%LOCALAPPDATA%\NetPilot\application-updates. При обычном запуске используется
только уже одобренная локальная версия; фоновой сетевой проверки нет.

Обновление установленной службы требует разрешения Windows и заканчивается
режимом наблюдения с выключенным управлением DNS. Исходные сетевые настройки
и пользовательские данные не входят в скачиваемый или распространяемый пакет.
