RtlineDnsPilot 0.1.16 — резервные IP при проверке HTTPS.

Когда первый IP проверяемого сайта принимает TCP, но зависает при TLS/HTTPS, монитор теперь пробует следующий IP внутри прежнего общего тайм-аута. Любой полученный HTTP-ответ завершает проверку: 403/429/5xx и перенаправления не обходятся повтором. DNS-ответы 0.0.0.0 и :: исключаются до HTTPS и объясняются в диагностике.

Сохранены штатные TLS/SNI и проверка сертификатов, предел HTTP-заголовков 64 КБ, пользовательские DNS-каналы, настройки, история и выбор канала. DNS-транспорт, relay и каталог не изменялись. Исправление не означает доступность всех сторонних DNS в каждой сети и не подтверждает вход в аккаунт или генерацию ответа.

В 0.1.12 и новее нажмите «Обновить программу». Старые 0.1.10/0.1.11 используют GitHub API: при исчерпанном лимите нужен один ручной переход на новый ZIP. Версии без кнопки обновления также требуют ручного перехода. В поставке сохранены 26 публичных DNS-профилей; пользовательские каналы, настройки и история сохраняются.

При обновлении установленной фоновой службы Windows запросит разрешение. Обновление службы заканчивается наблюдением с выключенным управлением DNS. Для дальнейшего управления нажмите «Включить управление DNS».

Сборки: Windows 10/11 x64 с .NET Desktop Runtime 10 и отдельный вариант Windows 7 SP1 x64 с .NET Desktop Runtime 6.0.36. Нативная приёмка Windows 7 и обновлённой установленной службы выполняется отдельно. Ранний выпуск без цифровой подписи.
