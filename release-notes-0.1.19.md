RtlineDnsPilot 0.1.19 — обновлённые DNS и точные причины отказа.

Нажмите «Обновить программу» в установленном приложении. Отдельный импорт DNS не нужен: новая ревизия каталога добавляет отсутствующие актуальные конфигурации при запуске GUI и обновлении установленной службы. Прежние каналы, ID, адреса, включённость, заметки, ручной/предпочтительный выбор и история сохраняются. Полный набор 0.1.18 из 26 каналов обычно становится набором из 30; если часть новых конфигураций уже есть, дубликаты пропускаются. При заполненной базе действует прежний предел 32 и уведомление об оставшихся добавлениях.

Обновлены два Bezmezhau-профиля: основной IPv4 143.20.64.55, резервный 31.58.216.201, DoH URL прежний. Владелец предупреждает, что общие адреса могут не работать в РФ. Для Comss добавлены два опубликованных DoH-варианта: 141.133.184.24/141.133.183.77 из официального mobileconfig и 109.73.193.146 из инструкций роутеров. Источники и ограничения приведены в заметках. Публикация адресов не гарантирует доступность из каждой сети. Непроверенные адреса GeoHide/Astracat не заменены догадками; старые варианты сохраняются.

Краткая ошибка теперь показывает первую и последнюю наблюдавшиеся IP-причины. Предшествующий IPv4 TLS-тайм-аут не теряется за последующей ошибкой IPv6 TCP. Все IP-попытки остаются в «Диагностике канала»; обычный status по-прежнему ограничен по размеру. Новые и прежние базовые конфигурации исключаются из клиентского «Поделиться DNS».

Проверки сертификатов/SNI, тайм-ауты, порядок IP, правила HTTP и автоматического выбора сохранены. Внешняя причина TLS-тайм-аутов не установлена и исправленной не объявляется. Публичный trace не подтверждает вход, генерацию и streaming. Поддержка динамического DoH bootstrap Zapret этим выпуском не добавляется.

При обновлении фоновой службы Windows запросит разрешение. После обновления управление DNS остаётся выключенным; включите его отдельной кнопкой. Сохраняются сборки Windows 10/11 x64 (.NET Desktop Runtime 10) и совместимости Windows 7 SP1 x64 (.NET Desktop Runtime 6.0.36). Нативная Windows 7 и сеть проблемного Windows 11 здесь не проверялись. Ранний выпуск без цифровой подписи.
