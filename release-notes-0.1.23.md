# RtlineDnsPilot 0.1.23

- Каналы с длительными сбоями проверяются реже, пока есть рабочий канал. После трёх измеренных сбоев подряд за две минуты или дольше пауза между проверками составляет минимум десять минут и минимум пять обычных интервалов.
- Успешная проверка возвращает обычную частоту. Если ни один проверенный канал в раунде не работает, отложенные резервы проверяются сразу. Кнопка «Проверить сейчас» проверяет все включённые каналы.
- В эту сборку входят [откат обновления и улучшения диагностики из 0.1.22](release-notes-0.1.22.md).
