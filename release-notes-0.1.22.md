# RtlineDnsPilot 0.1.22

- Кнопка «Откатить обновление» возвращает версию, которая была открыта до последнего завершённого обновления. Используется проверенная локальная копия. Для установленной службы Windows запрашивает разрешение и восстанавливает исходный DNS перед заменой службы. После отката управление DNS выключено.
- Откат сохраняется при следующем запуске. Настройки и история остаются на месте. Для службы требуется защищённая копия, созданная при её обновлении. Причина отказа отображается, если файлы отсутствуют или повреждены.
- При фатальной остановке посредника исходный DNS восстанавливается даже при паузе проверок. При ошибке восстановление можно повторить из окна.
- «Диагностика посредника» показывает этапы и коды недавних фактических DNS-запросов. Проверка «HTTPS ChatGPT» отдельно показывает ответ публичного адреса.
