Обновление добавляет недостающие DNS из встроенного каталога и сохраняет существующие каналы, их настройки и историю. В поставке 26 публичных профилей; устаревшие и не прошедшие последние проверки варианты отмечены в примечаниях и могут быть выключены. Результаты проверки из одной сети не гарантируют доступность в другой.

- «Добавить из JSON» дополняет список, пропускает дубликаты и не сбрасывает ручной выбор.
- Участие канала в проверках включается и выключается нажатием галочки или клавишей Space.
- Подсказка имени канала показывает текущую ошибку перед историческим примечанием.
- Увеличен ограниченный размер HTTPS-заголовков, чтобы ответы Gemini не отклонялись из-за прежнего предела 16 КБ. Проверка сертификата, имени сервера и запрет перехода с DoH на открытый DNS сохранены.

В 0.1.12 и новее нажмите «Обновить программу». Старые 0.1.10/0.1.11 используют GitHub API: при исчерпанном лимите нужен один ручной переход на новый ZIP. Версии без кнопки обновления также требуют ручного перехода.

При обновлении установленной фоновой службы Windows запросит разрешение. Обновление службы сохраняет каналы и историю и заканчивается наблюдением с выключенным управлением DNS. Для дальнейшего управления нажмите «Включить управление DNS».

Архив `win-x64` предназначен для Windows 10/11 x64 с .NET Desktop Runtime 10. Архив `win7-x64` — отдельный вариант совместимости для Windows 7 SP1 x64 с .NET Desktop Runtime 6.0.36; .NET 6 и Windows 7 больше не поддерживаются Microsoft. Сборка и автоматические проверки старого runtime выполняются на современной Windows; проверка на настоящем Windows 7 остаётся отдельной.

Проверяются общедоступные HTTPS-адреса, без входа в аккаунты. Зелёная проверка не подтверждает генерацию ответов, работу авторизованного Codex/WebSocket или безопасность DNS-провайдера. Причина отказа всех каналов на конкретном другом ПК по скриншоту не установлена.

Ранний выпуск без цифровой подписи. При разработке реальные DNS, служба Windows и UAC не изменялись.
